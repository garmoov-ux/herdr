# 👤 사장님(사용자) 프로필 및 작업 원칙 (USER_PROFILE.md)

> 이 파일은 헤르메스(Hermes) 아키텍처의 사용자 프로필(`USER.md`) 역할을 하며, 모든 팀(`w1`, `w2`, `w3`...)의 AI 직원이 출근 시 공유합니다.

## 기본 환경 및 선호사항
- **아키텍처:** **Herdr × Hermes CLI AgenticOS** (멀티 워크스페이스/페인 오케스트레이션 + 자기 진화형 기억/스킬 루프)
- **경로 원칙:** 특정 PC 드라이브 경로를 하드코딩하지 않고, 항상 저장소 루트 기준 상대 경로(`./memory/`, `./skills/`, `./teams/`, `./templates/roles/`)를 사용하여 어떤 PC에서든 즉시 동작하도록 유지할 것.
- **설명 스타일:** 비개발자도 직관적으로 이해할 수 있도록 비유와 핵심 요약 표를 사용해 명확하고 친절하게 설명할 것.
- **원격 제어 및 캡처 연동:**
  - 외출/모바일 원격 제어: **멀티 메신저 양방향 브릿지 (`python ./gateways/messenger_bridge.py`)**를 통해 텔레그램(Telegram), 슬랙(Slack), 디스코드(Discord)에서 모든 팀(`w1`, `w2`...)과 창(`p1`, `p2`...)을 실시간 제어
  - 클립보드 캡처: `Alt + V` 단축키로 `./captures/`에 자동 저장 및 입력창 첨부, 또는 *"클립보드 봐줘"* 명령 사용
